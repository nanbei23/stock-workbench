炒股小牛马 macOS 安装向导

目标平台：Intel x86_64 macOS 12 Monterey。这个页面会引导你完成依赖检查、安装、启动和验证。

v2.4.0 · 页面式 Step 安装包
1

解压安装包

把安装包解压到你希望长期存放的位置，例如“文稿”目录。不要放在下载目录后频繁移动。

2

检查依赖

需要 Python 3.12、Node.js/npm 和 macOS 自带的 launchctl。缺少 Python 或 Node 时，先通过 Homebrew 安装。

python3.12 --version node -v npm -v
3

开始安装

双击同目录下的 安装.command，或在终端运行下面命令。安装过程会创建虚拟环境、安装依赖、构建前端、初始化数据库并注册 launchd 服务。

./安装.command
4

打开工作台

安装完成后打开本地地址。如果 8000 端口被占用，重新执行部署脚本并指定其他端口。

http://127.0.0.1:8000
打开工作台
5

升级和恢复

后续版本可双击 升级.command。升级前会尝试备份数据库；恢复入口在“设置 -> 数据管理”。

./升级.command
安全提示：本项目是本地工作台，交易和持仓写库都在本机 SQLite 中完成。真实交易仍需你在券商端独立确认。
